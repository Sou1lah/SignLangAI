# LiveKit UI Showcase

Single local entry point for the categorized learning-app design reference and display-only UI kit.
Run from the repository root with `pnpm --filter ui-library storybook`.
Open http://localhost:6006; browse Foundations, Buttons, Call, and Gamification for progress, exercise, and reward components.
Call controls are static previews only and are not connected to a LiveKit room.
Button styling references the MIT-licensed `thirdparty/duolingo-clone`. Its heart and points icons are included with attribution in `THIRD_PARTY_NOTICES.md`.
The clone has no streak component, so the weekly streak card is an original visual template; other icons use Lucide.
