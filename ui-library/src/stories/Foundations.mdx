# Learning UI Design System

A categorized, display-only visual reference for the learning app: bright action green, friendly rounded shapes, clear type hierarchy, and simple reusable interface patterns. This guide is based on the supplied design analysis; Duolingo mascots, logos, proprietary fonts, and sounds are not included.

## Color palette

Use saturated green for primary actions and selected states. Navy anchors display text; blue, red, orange, gold, and purple are supporting accents.

## Spacing and layout

Use an 8px-based rhythm, 16px page gutters, a readable content width, and generous section separation.

| Token | Value |
| --- | ---: |
| xs | 8px |
| sm | 10px |
| md | 12px |
| base | 16px |
| lg | 24px |
| xl | 32px |
| xxl | 48px |
| section | 96px |

Layout reference: centered content around 1024px wide, 16px outer gutters, and about 96px between major page sections.

## Shapes and elevation

Rounded rectangles and full pills carry the friendly interface tone. Keep elevation flat; primary buttons use a short solid bottom lip rather than diffuse shadows.

Content cards sit flat on the canvas. Semantic badges communicate streak, error, and milestone states with text as well as color.

## Forms and feedback

Inputs use a 48px control height, 8px radius, and clear focus treatment. Hairline dividers separate content without visual weight.
