# UML diagrams

Draw.io source diagrams and exported images for project design. Use the subfolders to organize diagrams by type.

Name source files `NN-type-subject.drawio`, for example `01-usecase-learner.drawio`.
Open diagrams with [draw.io Desktop](https://www.drawio.com/), [app.diagrams.net](https://app.diagrams.net/), or the [VS Code draw.io extension](https://marketplace.visualstudio.com/items?itemName=hediet.vscode-drawio).

The `.drawio` files are empty placeholders; no design has been drawn yet.
