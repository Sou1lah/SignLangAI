# Memoire

Workspace for research, notes, drafts, and references.

| Folder | What belongs here |
|---|---|
| [01-problematique/](01-problematique/) | Problem statement and research questions |
| [02-recherche/papers/](02-recherche/papers/) | Papers to read; record source and license |
| [02-recherche/notes/](02-recherche/notes/) | Reading notes based on `templates/research-note.md` |
| [02-recherche/datasets/](02-recherche/datasets/) | Dataset links and license notes only; do not store downloaded datasets here |
| [03-memo/](03-memo/) | Memos in PDF or Markdown |
| [04-redaction/](04-redaction/) | Thesis chapters and drafts |
| [05-references/](05-references/) | BibTeX bibliography and Zotero exports |
| [templates/](templates/) | Memo, research-note, and decision-record templates |

Use [Zotero](https://www.zotero.org/) to manage references. Use [Git LFS](https://git-lfs.com/) for any file larger than 50 MB.
